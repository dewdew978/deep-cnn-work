Getting Start
1. Open Visual Studio Code
2. Select "File > Open Folder" (At manu bar)
3. Go to "New Volume(D:) > Deep Learning for Beginners Image and Video Processing" and Open
4. Select "Terminal > New Terminal"
5. type "conda --version" then enter in terminal
6. You should see "conda 24.5.0"

Create environment & Install packages
1. type "conda create --name <enter your env name here>" then enter
2. read detail and type "yes"
3. then activate your environment "conda activate <your env name>"
4. then install pytorch "conda install pytorch torchvision pytorch-cuda=11.8 -c pytorch -c nvidia"
5. after that install additional packages "conda install --yes --file requirements.txt"
